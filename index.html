🎻 중학교 음악 창작 탐색기

악기 음색, 장조·단조, 코드 진행을 직접 들어보며
표현하고 싶은 장면에 어울리는 소리를 찾아보세요.

🎧 악기를 누르면 그때 음원을 불러옵니다
안내: 브라우저 정책상 소리가 바로 켜지지 않습니다. 아래 「소리 시작하기」 버튼을 한 번 누른 뒤에 악기/코드 듣기를 사용해 주세요. 아직 준비가 안 된 상태에서는 연주가 실행되지 않습니다.
같은 악기도 연주 방법과 음의 높이에 따라 다양한 느낌을 표현할 수 있어요. 짧은 멜로디를 들어보고, 비교함에 악기를 담아 같은 선율로 음색을 비교해 보세요.

🔍 악기 비교함 (0/4)

같은 짧은 구절(약 3–5초)을 선택한 악기로 차례대로 들어볼 수 있어요. 최대 4개까지 담을 수 있습니다. (타악기는 비교함 제외)

장조는 밝고 안정적인 느낌, 단조는 어둡거나 긴장된 느낌이 나는 경우가 많아요. 아래 피아노에서 주황 표시 = 음계에 들어가는 건반, 밝은 점등 = 지금 울리는 건반입니다.

🎹 건반 위치 보기 (C2–C6)

좌우로 스크롤해 전체 건반을 볼 수 있어요. 버튼을 누르면 해당 음이 표시됩니다.
음계/코드에 포함 현재 재생 중

C 장조 (Major)

밝고 안정적인 느낌 · C - D - E - F - G - A - B

C 단조 (Minor)

어둡거나 긴장된 느낌 · C - D - Eb - F - G - Ab - Bb
